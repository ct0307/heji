- 核验授权逐项覆盖上述操作，且实际MySQL主机属于本机白名单。
- 只通过应用入口加载本地配置，不打印、复制或手工打开`.env`和凭据。
- 识别M4写进程及bench连接，确认无新负载与其他写进程后进入维护窗口；不停止5173/3000上的无关服务，不盲目结束进程。

## 已有受保护入口

```powershell
# 仅在第1项获准后，临时设置进程级HEJI_ALLOW_MIGRATION=yes
npm run db:window:migrate -- --apply --database=heji_m4_bench --maintenance

# 仅在第2项获准且迁移核验通过后，临时设置进程级HEJI_ALLOW_M4=yes

# 仅在第3项获准且备份校验通过后，用第2项实际生成文件名替换参数
```

这些命令记录本次批准的范围，不是未来重复执行许可。每项结束后恢复进程变量。任何异常立即停止后续阶段，保留证据、源库、新文件及不完整目标；清理或失败重试需要新的明确许可。

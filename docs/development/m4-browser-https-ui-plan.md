## 受控方案

浏览器验收仅验证本机SPA深链、登录与会话、虚构账本读写、PREVIEW_STALE后需重新确认以及WSS连接；沿用已批准的本地端口与heji_dev虚构账号/数据范围，不打印Cookie、会话或CSRF值。API/Nginx只在获批的回环端口启动，结束后停止本轮实例。

验收后按本次导入证书的精确指纹，从当前用户根存储移除该证书，并只读核对其已不存在；不删除或改动其他证书。若导入被拒、证书链仍不受信、浏览器提示任何其他证书问题或回滚核验失败，立即停止浏览器测试并报告，不绕过告警、不更换证书、不重试。

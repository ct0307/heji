# 恢复分阶段计时离线验收

日期：2026-11-19。本文记录分阶段计时首次离线验收，当时新目标尚未加入白名单。后续状态见[新目标离线验收](m4-restore-timed-target-verification.md)和[独立恢复方案](m4-restore-timed-acceptance.md)。

## 变更

- 新增[RestoreTimer](../../tests/m4/restore-timing.ts)，使用performance.now单调计时，记录running/completed/failed、父子阶段、偏移与耗时；观察回调异常不覆盖原业务异常。
- [恢复入口](../../tests/m4/backup.ts)覆盖文件校验、流式预检、建空schema、数据库连接、列/主键核对、导入、逐表摘要、迁移元数据、全部外键、历史份额、当前版本、余额守恒、003逐账本余额/期间报表、确认/冲正/窗口计数和提交。不逐行打日志，不修改财务SQL、迁移SQL和原事务顺序。
- [余额核验](../../tests/m4/balance-verification.ts)增加可选计时参数；原无参数调用兼容。计时包含查询与结果断言，损坏即记录failed并停止，后续检查/commit不会继续。
- 保持恢复报告外层`heji-m4-restore-verification-v1`及原字段，新增`timing`（自身格式`heji-m4-restore-timing-v1`），保留现有Word报告读取器兼容。旧恢复JSON、历史Word文件不改写。
- 总耗时仍从入口到成功commit返回；unmeasuredMs记录门禁/包装开销，子项不双算。证据文件写入和连接收尾仍不计入30分钟，与既有结果口径一致。日志只输出阶段与经过验证的表名/顺序号，不输出SQL、ID、行值或异常内容。

# 双界面与B视觉优化设计

日期：2026-11-19。用户已明确保留A/B两种界面、默认A，B选择「墨蓝灰＋无衬线字体」。沿用已审核的两套布局。本轮直接实施上述选择。

## 用户行为

公共页与登录后的导航均提供「界面设置」。选择A「雾青工作台」或B「墨蓝账页」立即生效，保持当前路由与已填写内容。新浏览器默认A；偏好只保存在当前浏览器，不宣称跨设备同步。读取非法/失效偏好回退A；无法保存时本次切换仍生效，提示刷新后可能恢复默认。Escape关闭设置，恢复入口焦点。

## 展示

A桌面采用浅雾绿侧栏和深绿个人余额，主内容为任务工作区；手机导航收紧但保留设置入口。B桌面采用顶部横向导航，白色账页、纵向明细线、结算收据；手机单列。两种布局都提供全部现有功能。

B颜色：底色#f5f6f8、账页#ffffff、石墨文字#252d3c、说明#626b7a、墨蓝强调#465bb1、边线#dce1e9。中文统一微软雅黑UI/苹方/微软雅黑无衬线；数字使用Segoe UI及等宽数字特性。正文/按钮14px、说明至少12px、关键财务规则13px，标题32/28px、主金额44/40px；主要操作至少44px。保留危险、成功与窗口提示的语义和足够对比度。

## 实现边界

一套RouterView和业务组件，根data-interface属性驱动样式。禁止以界面值作为key或条件重挂载面板；切换不改变账本/标签路由，不调用业务写入、不申请窗口、不清除草稿或确认勾选。财务金额、版本门禁、权限、幂等及窗口逻辑沿用现有代码。

新增独立偏好模块、设置组件及appearance.css，样式在现有m1/m2/m3后加载。仅必要时为现有模板加展示容器/类名。旧work原型保留。无依赖安装、数据库迁移、数据库写入、部署或全局配置。

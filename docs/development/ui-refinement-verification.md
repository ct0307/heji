## 中间问题与修正

1. 分类筛选的脚本精确label匹配参与了option文字，读取实际可访问树后改用combobox名称定位。新增卡片空白点击检查也纠正一次嵌套has作用域定位。失败原记录保留。
2. 旧隔离基建会主动关闭WS，生产同步按设计补查，干扰主题请求计数。新脚本模拟SUBSCRIBE/SUBSCRIBED并保持隔离连接，等待live及初始补查完成再取基线；生产同步及“无额外请求”断言均未放宽。两次相关失败保留。
3. 真实长昵称P2先由独立模拟诊断复现：360px下A横宽523/B545，390px下A529/B551。给署名子span添加min-width:0与overflow-wrap:anywhere，并检查分摊/预览姓名同类约束；最终边界组通过。未使用隐藏溢出或截断财务数字掩盖问题。
4. 首轮成功31项/32布局/36图保留为历史；第一轮39项/36布局/38图也保留为中间版本。截图发现手机概览压缩后大额数字小数被拆行，改为整块换行；B桌面行距、长昵称问题均已在最终冻结CSS后重跑39项。

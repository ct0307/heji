## 推荐的首次编码验收点

用两个独立登录会话完成一条最小账本流程：创建账本、第二位成员加入、记录一笔支出并查看分摊及余额、登记一笔转账、另一方确认后核对余额。服务端必须验证账本成员关系，所有金额使用整数分；该流程有自动化测试或可重复的验收步骤。

这个首个验收点用于尽早证明前后端、数据库和财务规则能够协同工作。其余 P1 仍按设计文档推进。

## 安全与范围约束

- 本准备阶段不安装 npm 包或全局工具，不接入真实支付，不写入真实密钥。
- 项目初始化、依赖安装和部署应在后续阶段分别记录命令、来源和验证结果。
- 用户界面草图中的模拟姓名和账务数据仅供演示；正式种子数据应明确为虚构数据。
